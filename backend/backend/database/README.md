# database 目录说明

## 导入顺序

- 生产环境：只导入 `01-init.sql`，再按实际发布顺序执行后续补丁 SQL。
- 本地联调 / 演示环境：先导入 `01-init.sql`，再导入 `seed-local-dev.sql`。

## 文件职责

- `01-init.sql`：仅包含表结构、索引、外键和触发器，适合作为生产初始化基线。
- `seed-local-dev.sql`：仅包含本地演示账号、文章、评论、点赞、收藏、操作日志等示例数据，禁止直接导入生产环境。

## 上线注意事项

- 生产环境不要导入 `seed-local-dev.sql`，其中包含演示用户、示例文章和操作日志。
- 如果误导入了本地种子数据，优先用最近一次数据库备份回滚，不要在线上逐表手工删改。
- 后续如果新增结构补丁，保持“结构 SQL”和“本地样例数据”继续分离，避免再次把演示数据带到线上。
