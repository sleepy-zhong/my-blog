# 数据库执行指南

## 评论系统数据库修改

### 执行评论系统数据库修改

由于Windows PowerShell不支持 `<` 重定向操作符，请使用以下方法之一：

#### 方法1: 使用Get-Content管道（推荐）
```powershell
# 执行完整初始化脚本（包含用户创建）
Get-Content init-comment-system.sql | mysql -u root -p techblogdb

# 或者分别执行
Get-Content fix-comment-database.sql | mysql -u root -p techblogdb
Get-Content create-test-users-with-password.sql | mysql -u root -p techblogdb
```

#### 方法2: 使用cmd.exe
```powershell
cmd /c "mysql -u root -p techblogdb < fix-comment-database.sql"
```

#### 方法3: 手动复制执行
1. 打开MySQL Workbench或其他MySQL客户端
2. 复制 `fix-comment-database.sql` 文件内容
3. 在MySQL客户端中执行

#### 方法4: 使用MySQL命令行
```bash
# 如果MySQL在PATH中
mysql -u root -p techblogdb -e "source fix-comment-database.sql"
```

### 评论系统修改内容

执行 `fix-comment-database.sql` 脚本将完成以下修改：

1. **修改评论默认状态**：从 `pending` 改为 `approved`
2. **添加删除权限字段**：新增 `CanDelete` 字段，默认值为 `1`
3. **更新现有数据**：将所有待审核评论设为已审核
4. **插入测试数据**：创建楼中楼评论结构用于测试

### 验证评论系统修改结果

执行完成后，可以运行以下查询验证：

```sql
-- 检查评论表结构
DESCRIBE comments;

-- 检查默认状态
SHOW CREATE TABLE comments;

-- 查看测试数据（楼中楼结构）
SELECT 
    CommentID,
    PostID,
    UserID,
    ParentCommentID,
    Content,
    Status,
    CanDelete,
    CreatedAt
FROM comments 
WHERE PostID = 1 
ORDER BY ParentCommentID IS NULL DESC, CommentID;

-- 验证楼中楼结构
SELECT 
    c1.CommentID as '主评论ID',
    c1.Content as '主评论内容',
    c2.CommentID as '回复ID',
    c2.Content as '回复内容',
    c3.CommentID as '回复的回复ID',
    c3.Content as '回复的回复内容'
FROM comments c1
LEFT JOIN comments c2 ON c1.CommentID = c2.ParentCommentID
LEFT JOIN comments c3 ON c2.CommentID = c3.ParentCommentID
WHERE c1.PostID = 1 AND c1.ParentCommentID IS NULL
ORDER BY c1.CommentID, c2.CommentID, c3.CommentID;
```

## 通用数据库操作

### Windows PowerShell 执行SQL脚本

#### 方法1: 使用Get-Content管道
```powershell
Get-Content 脚本文件名.sql | mysql -u root -p 数据库名
```

#### 方法2: 使用cmd.exe
```powershell
cmd /c "mysql -u root -p 数据库名 < 脚本文件名.sql"
```

#### 方法3: 手动复制执行
1. 打开MySQL Workbench或其他MySQL客户端
2. 复制SQL文件内容
3. 在MySQL客户端中执行

#### 方法4: 使用MySQL命令行
```bash
# 如果MySQL在PATH中
mysql -u root -p 数据库名 -e "source 脚本文件名.sql"
```

## 常见问题

### 1. MySQL命令未找到
- 确保MySQL已安装并添加到系统PATH
- 或使用完整路径：`C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe`

### 2. 权限错误
- 确保使用有足够权限的用户（如root）
- 检查数据库是否存在：`SHOW DATABASES;`

### 3. 字符编码问题
- 确保SQL文件使用UTF-8编码
- 在MySQL中设置：`SET NAMES utf8mb4;`

### 4. 字段已存在错误
如果遇到 `CanDelete` 字段已存在的错误，可以跳过该步骤：
```sql
-- 检查字段是否存在
SHOW COLUMNS FROM comments LIKE 'CanDelete';

-- 如果不存在才添加
ALTER TABLE `comments` ADD COLUMN `CanDelete` tinyint(1) DEFAULT 1 COMMENT '用户是否可删除';
```

### 5. 测试数据重复插入
如果测试数据已存在，可以清空后重新插入：
```sql
-- 清空测试数据（谨慎使用）
DELETE FROM comments WHERE PostID = 1;

-- 重新插入测试数据
-- 执行 fix-comment-database.sql 中的 INSERT 语句
```
