## 1. 用户与权限

### 1.1 用户注册
- **POST** `/api/users/register`
- **功能**：新用户注册
- **是否鉴权**：否
- **请求参数**：
| 字段名      | 位置 | 类型   | 必填 | 说明     | 示例         |
| ----------- | ---- | ------ | ---- | -------- | ------------ |
| username    | body | string | 是   | 用户名   | testuser     |
| email       | body | string | 是   | 邮箱     | test@xx.com  |
| password    | body | string | 是   | 密码     | 123456       |
| phoneNumber | body | string | 否   | 手机号   | 13800000000  |

- **返回数据**：
| 字段名   | 类型   | 说明     |
| -------- | ------ | -------- |
| code     | int    | 状态码   |
| message  | string | 提示信息 |
| data     | object | 用户信息 |

- **返回示例**：
```json
{
  "code": 0,
  "message": "注册成功",
  "data": {
    "UserID": 1,
    "Username": "testuser",
    "Email": "test@xx.com"
  }
}
```
- **错误示例**：
```json
{
  "code": 1,
  "message": "用户已存在"
}
```

