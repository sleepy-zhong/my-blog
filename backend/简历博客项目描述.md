# 博客项目简历描述

## 项目概述
**TechBlog个人博客系统** | 2024年 | 全栈开发项目

一个功能完整的现代化博客系统，支持多角色权限管理、内容管理、评论系统等核心功能，采用前后端分离架构，具备完整的生产环境部署能力。

---

## 技术栈

### 后端技术
- **运行环境**: Node.js 18+ 
- **Web框架**: Express.js 5.x
- **数据库**: MySQL 8.0 + Sequelize ORM
- **身份认证**: JWT (JSON Web Token)
- **文件处理**: Multer + Sharp (图片处理)
- **文档解析**: Mammoth (Word文档) + Markdown-it
- **邮件服务**: Nodemailer
- **API文档**: Swagger UI + JSDoc

### 数据库设计
- **ORM框架**: Sequelize
- **数据库**: MySQL 8.0，支持UTF8MB4编码
- **表结构**: 10+张核心表，包含用户、文章、评论、分类、标签、附件、操作日志等
- **关系设计**: 多对多关联（用户-角色、文章-分类、文章-标签）、一对多关联（用户-文章、文章-评论）

### 运维部署
- **进程管理**: PM2集群模式
- **反向代理**: Nginx
- **SSL证书**: Let's Encrypt
- **容器化**: 支持Docker部署
- **监控日志**: PM2监控 + 自定义操作日志

---

## 核心功能模块

### 1. 用户权限系统
- **多角色管理**: 管理员、编辑、作者、订阅者四种角色
- **灵活权限**: 基于角色的权限控制(RBAC)
- **多种登录**: 支持用户名、邮箱、手机号三种登录方式
- **安全特性**: BCrypt密码加密、JWT身份验证、防暴力破解

### 2. 内容管理系统
- **富文本编辑**: 支持Markdown格式，自动生成摘要
- **多格式导入**: 支持Word、PDF、HTML等文档格式解析
- **版本控制**: 文章修订历史，支持版本回滚
- **SEO优化**: 友好URL、自定义Slug、元数据管理
- **分类标签**: 多级分类、多标签关联

### 3. 评论互动系统
- **楼中楼回复**: 支持无限层级的评论回复
- **评论管理**: 审核、屏蔽、恢复等状态管理
- **实时通知**: 评论邮件通知功能

### 4. 文件管理系统
- **多格式支持**: 图片、文档、压缩包等文件类型
- **智能处理**: 图片自动压缩、格式转换
- **关联管理**: 文件与文章的关联关系
- **安全控制**: 文件类型检查、大小限制

### 5. 运营分析系统
- **操作日志**: 全站操作自动记录，支持审计追踪
- **数据统计**: 文章浏览量、用户活跃度等统计
- **系统监控**: 接口性能监控、错误日志收集

## 技术难点与解决方案

### 1. 复杂权限管理
**难点**: 多角色、多权限的复杂权限体系设计
**解决方案**: 采用RBAC模型，设计用户-角色-权限三层关系，通过中间件实现权限检查

### 2. 评论系统的树形结构
**难点**: 楼中楼无限嵌套的评论回复系统
**解决方案**: 使用自关联表结构，前端递归渲染，后端提供平铺和树形两种数据格式

### 3. 文件处理与存储
**难点**: 多格式文件上传、处理和存储优化
**解决方案**: 使用Multer处理上传，Sharp进行图片压缩，Mammoth解析Word文档

### 4. 数据库性能优化
**难点**: 复杂查询的性能优化，特别是文章列表的多条件筛选
**解决方案**: 建立复合索引，使用Sequelize的include优化关联查询，实现智能分页

### 5. 生产环境部署
**难点**: 从开发到生产的完整部署流程
**解决方案**: 编写详细的部署文档，使用PM2+Nginx+SSL的标准部署架构
