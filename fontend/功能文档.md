# TechBlogDB 前端详细功能文档

## 1. 用户端页面与功能

### 1.1 认证与用户中心
- **注册页**
  - 表单字段：用户名（必填）、邮箱（必填）、密码（必填）、手机号（可选）
  - 校验：用户名/邮箱/手机号唯一性校验，密码强度校验
  - 注册接口：`POST /api/users/register`，成功后自动登录或跳转登录页
  - 错误处理：用户已存在、参数错误、验证码校验失败等
- **登录页**
  - 表单字段：用户名/邮箱/手机号、密码
  - 登录接口：`POST /api/users/login`，成功后保存 JWT 到 localStorage
  - 支持多方式登录，登录失败友好提示
- **找回密码页**
  - 表单字段：邮箱/手机号、新密码、验证码
  - 找回密码接口：`POST /api/users/forgot-password`，重置密码接口：`POST /api/users/reset-password`
  - 验证码发送、校验、倒计时、错误提示
- **个人中心页**
  - 展示：用户名、邮箱、手机号、头像、简介、注册时间等
  - 编辑：PUT `/api/users/me`，支持修改昵称、简介、头像
  - 修改密码：PUT `/api/users/me/password`，原密码+新密码校验
  - 我的文章、我的评论列表，分页、跳转详情
  - 登出：POST `/api/users/logout`，清除 token

### 1.2 文章与内容浏览
- **首页**
  - 轮播 Banner（可配置）、欢迎语、最新文章列表（分页，GET `/api/articles`）
  - 文章卡片：标题、摘要、作者、时间、标签、分类、封面图、浏览量
  - 跳转文章详情、分类、标签页
- **文章列表页**
  - 支持分页、搜索（keyword）、分类/标签筛选（category/tag）
  - 接口：GET `/api/articles?page=1&pageSize=10&keyword=xxx&category=1&tag=2`
  - 支持草稿、已发布、归档等状态筛选
- **文章详情页**
  - 展示：标题、内容、作者、时间、标签、分类、封面图、浏览量
  - 评论区（见下）、附件列表（GET `/api/attachments?postId=xxx`）、历史修订（GET `/api/articles/:id/revisions`）
  - 支持点赞、收藏、分享、浏览量统计（PUT `/api/articles/:id/view-count`）
- **分类/标签页**
  - 分类树/标签云展示（GET `/api/categories/tree`、`/api/tags`）
  - 分类/标签下文章列表（GET `/api/categories/:id/articles`、`/api/tags/:id/articles`）
- **搜索页**
  - 支持关键字搜索文章、标签、作者，接口同文章列表

### 1.3 评论系统
- **评论区组件**
  - 评论列表（GET `/api/comments/:articleId`），支持分页、楼中楼展示
  - 发表评论（POST `/api/comments/:articleId`），支持回复、父评论ID
  - 删除评论（DELETE `/api/comments/:id`），仅本人/管理员可见
  - 评论审核状态提示（如“待审核”、“已屏蔽”）
  - 评论点赞、举报（可扩展）

### 1.4 其他
- **附件上传/预览组件**
  - 上传（POST `/api/attachments`，multipart/form-data），支持图片/文档
  - 下载/删除（GET/DELETE `/api/attachments/:id`），预览图片、文档
  - 关联文章、显示附件列表
- **全局导航栏/侧边栏**
  - 首页、文章、分类、标签、登录/注册、个人中心、后台入口，当前路由高亮
  - 响应式菜单、移动端抽屉
- **全局提示与错误处理**
  - 统一接口响应处理，后端 code/message 友好提示
  - 401/403 跳转登录或提示无权限，404/500 页面
- **响应式布局与夜间模式**
  - Tailwind CSS，支持暗色模式切换，自动适配系统主题

## 2. 管理后台页面与功能

### 2.1 用户管理
- 用户列表（GET `/api/users`，分页、搜索、筛选、启用/禁用、分配角色、删除）
- 用户详情（GET `/api/users/:id`）、编辑（PUT `/api/users/:id`）、重置密码（PUT `/api/users/:id/password`）
- 批量删除（POST `/api/users/batch-delete`）、分配/移除角色（POST/DELETE `/api/users/:id/roles`）

### 2.2 文章管理
- 文章列表（GET `/api/articles`，分页、搜索、筛选、审核、删除、修订历史、封面上传）
- 新建/编辑文章（POST/PUT `/api/articles`，富文本/Markdown编辑器、封面、摘要、分类、标签、状态）
- 文章详情、归档/发布、浏览量统计、历史修订（GET `/api/articles/:id/revisions`、POST `/api/articles/:id/restore/:revisionId`）

### 2.3 评论管理
- 评论列表（GET `/api/comments/:articleId`，分页、搜索、审核、屏蔽、恢复、删除）
- 评论详情、楼中楼展示，审核/屏蔽/恢复（PUT `/api/comments/:id/status`）

### 2.4 分类/标签管理
- 分类/标签列表（GET `/api/categories`、`/api/tags`，树结构、分页、搜索、增删改查、多级分类）
- 分类/标签详情、关联文章（GET `/api/categories/:id/articles`、`/api/tags/:id/articles`）

### 2.5 附件管理
- 附件列表（GET `/api/attachments`，分页、搜索、上传、预览、删除、关联文章）

### 2.6 操作日志
- 日志列表（GET `/api/logs`，分页、搜索、筛选、详情）
- 日志详情（GET `/api/logs/:id`，操作类型、用户、时间、内容）

### 2.7 系统设置
- 站点信息、邮件配置、社交链接、Logo/Favicon、夜间模式（GET/PUT `/api/settings`）

## 3. 前端通用功能
- **鉴权与权限控制**：基于 JWT，前端路由守卫，接口请求自动带 token，401/403 自动跳转登录或提示
- **接口统一封装**：axios/fetch 封装，支持全局 loading、错误处理、消息提示
- **富文本/Markdown 编辑器**：文章编辑、评论支持，图片拖拽上传
- **文件上传/下载**：支持拖拽、进度、预览，接口与附件管理一致
- **响应式与主题切换**：Tailwind CSS，支持暗色模式，自动适配
- **SEO 优化**：文章页、首页、分类/标签页 meta 信息，支持 SSR/预渲染（可选）
- **代码高亮、图片懒加载、滚动加载**：提升阅读体验

2. 跨域（CORS）配置
2.1 本地开发（Vite）
在 vite.config.ts 添加代理：
Apply to 功能文档.md
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8000', // 后端地址
        changeOrigin: true,
        rewrite: path => path.replace(/^\/api/, '/api'),
      },
    },
  },
})
这样前端请求 /api/... 会自动代理到后端，解决开发时的跨域问题。
2.2 生产环境
后端需配置 CORS 允许前端域名（如 Access-Control-Allow-Origin）。
推荐前后端同域部署或 Nginx 反向代理。

src/api/index.ts：
Apply to 功能文档.md
import axios from 'axios'

const instance = axios.create({
  baseURL: '/',
  timeout: 10000,
})

// 请求拦截器：自动加 token
instance.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// 响应拦截器：统一错误处理
instance.interceptors.response.use(
  res => res.data,
  err => {
    // 401/403 跳转登录
    if (err.response?.status === 401) {
      window.location.href = '/login'
    }
    // 全局错误提示
    alert(err.response?.data?.message || '请求失败')
    return Promise.reject(err)
  }
)

export default instance
4. 页面开发举例
4.1 登录页（Login.vue）
Apply to 功能文档.md
<template>
  <div class="min-h-screen flex items-center justify-center">
    <form @submit.prevent="onLogin" class="bg-white p-8 rounded shadow w-full max-w-md flex flex-col gap-4">
      <input v-model="form.username" placeholder="用户名/邮箱/手机号" required class="input" />
      <input v-model="form.password" type="password" placeholder="密码" required class="input" />
      <button type="submit" class="btn-primary">登录</button>
    </form>
  </div>
</template>

<script setup>
import { ref } from 'vue'
import { login } from '@/api/user'
import { useRouter } from 'vue-router'

const router = useRouter()
const form = ref({ username: '', password: '' })

async function onLogin() {
  try {
    const res = await login(form.value)
    if (res.code === 0 && res.data.token) {
      localStorage.setItem('token', res.data.token)
      router.push('/')
    } else {
      alert(res.message)
    }
  } catch (e) {}
}
</script>
4.2 文章列表页（PostList.vue）

<script setup>
import { ref, onMounted } from 'vue'
import { getArticles } from '@/api/article'

const articles = ref([])
const page = ref(1)

async function fetchArticles() {
  const res = await getArticles({ page: page.value, pageSize: 10 })

  }
}
onMounted(fetchArticles)
</script>
5. 路由与权限
路由守卫：未登录访问需要权限的页面自动跳转登录
管理后台页面需校验用户角色
Apply to 功能文档.md
// router/index.ts
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')
  if (to.meta.requiresAuth && !token) {
    next('/login')
  } else {
    next()
  }
})
