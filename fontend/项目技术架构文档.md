### 技术选型理由

**前端技术栈选择**：
- **Vue 3**: 组合式API提高代码复用性，性能比Vue2提升40%+
- **TypeScript**: 大型项目必备，编译时类型检查，IDE智能提示
- **Vite**: HMR速度快，开发体验极佳，生产构建优化
- **Pinia**: 轻量级状态管理，TypeScript支持更好
- **TailwindCSS**: 原子化CSS，快速构建响应式界面

**后端技术栈选择**：
- **Node.js + Express**: JavaScript全栈，学习成本低，生态丰富
- **JWT**: 无状态认证，支持分布式部署
- **MySQL**: ACID特性保证数据一致性，适合复杂关联查询

### 控制器层设计

**文章控制器示例**：
```javascript
class ArticleController {
  // 创建文章
  async createArticle(req, res) {
    const transaction = await db.transaction()
    try {
      // 1. 创建文章主体
      const article = await Article.create({
        title: req.body.title,
        content: req.body.content,
        userId: req.user.id,
        status: 'draft'
      }, { transaction })
      
      // 2. 处理分类和标签关联
      if (req.body.categoryIds) {
        await article.setCategories(req.body.categoryIds, { transaction })
      }
      
      // 3. 创建首次修订记录
      await ArticleRevision.create({
        articleId: article.id,
        content: req.body.content,
        userId: req.user.id
      }, { transaction })
      
      await transaction.commit()
      res.status(201).json({ code: 0, data: article })
    } catch (error) {
      await transaction.rollback()
      res.status(500).json({ code: 500, message: error.message })
    }
  }
  
  // 获取文章列表（支持搜索、分页、筛选）
  async getArticles(req, res) {
    const { page = 1, pageSize = 10, keyword, status, category, tag } = req.query
    
    const whereClause = {}
    if (keyword) {
      whereClause[Op.or] = [
        { title: { [Op.like]: `%${keyword}%` } },
        { content: { [Op.like]: `%${keyword}%` } }
      ]
    }
    if (status) whereClause.status = status
    
    const include = [
      { model: User, attributes: ['id', 'username'] },
      { model: Category, where: category ? { id: category } : undefined },
      { model: Tag, where: tag ? { id: tag } : undefined }
    ]
    
    const articles = await Article.findAndCountAll({
      where: whereClause,
      include,
      limit: parseInt(pageSize),
      offset: (parseInt(page) - 1) * parseInt(pageSize),
      order: [['createdAt', 'DESC']]
    })
    
    res.json({
      code: 0,
      data: {
        list: articles.rows,
        total: articles.count,
        page: parseInt(page),
        pageSize: parseInt(pageSize)
      }
    })
  }
}
```

### 文章发布流程

**状态流转图**：
```
草稿(draft) ──发布──> 已发布(published) ──归档──> 已归档(archived)
     │                        │                      │
     └────────编辑────────────┘                      │
     │                                               │
     └─────────────────删除─────────────────────────┘
```

**发布业务逻辑**：
```javascript
async publishArticle(articleId, userId) {
  const transaction = await db.transaction()
  try {
    // 1. 验证文章所有权
    const article = await Article.findOne({
      where: { id: articleId, userId },
      transaction
    })
    if (!article) throw new Error('文章不存在或无权限')
    
    // 2. 检查必要字段
    if (!article.title || !article.content) {
      throw new Error('标题和内容不能为空')
    }
    
    // 3. 更新状态和发布时间
    await article.update({
      status: 'published',
      publishedAt: new Date()
    }, { transaction })
    
    // 4. 同步附件状态（将临时附件转为正式附件）
    await this.syncArticleAttachments(articleId, transaction)
    
    // 5. 记录操作日志
    await OperationLog.create({
      userId,
      action: 'publish_article',
      resourceType: 'article',
      resourceId: articleId,
      details: `发布文章: ${article.title}`
    }, { transaction })
    
    await transaction.commit()
    return { success: true, article }
  } catch (error) {
    await transaction.rollback()
    throw error
  }
}
```

### 图片上传与管理

**图片处理流程**：
```javascript
async handleImageUpload(file, options = {}) {
  // 1. 计算文件哈希，实现去重
  const hash = await calculateSHA256(file)
  const existing = await Attachment.findOne({ where: { hash } })
  if (existing) {
    return { attachmentId: existing.id, isNew: false }
  }
  
  // 2. 图片压缩和格式转换
  const processedImage = await compressImage(file, {
    quality: options.quality || 80,
    maxWidth: options.maxWidth || 1920,
    maxHeight: options.maxHeight || 1080
  })
  
  // 3. 生成唯一文件名和存储路径
  const ext = path.extname(file.originalname)
  const filename = `${hash}${ext}`
  const filepath = path.join('uploads', 'images', filename)
  
  // 4. 保存文件到磁盘
  await fs.promises.writeFile(filepath, processedImage)
  
  // 5. 创建附件记录
  const attachment = await Attachment.create({
    filename,
    originalname: file.originalname,
    mimetype: file.mimetype,
    size: processedImage.length,
    path: filepath,
    hash,
    uploadedBy: options.userId,
    status: options.postId ? 'active' : 'temporary'
  })
  
  return { attachmentId: attachment.id, isNew: true }
}
```

### 评论系统设计

**楼中楼评论查询**：
```javascript
async getCommentsTree(articleId) {
  // 1. 获取所有评论（包括回复）
  const allComments = await Comment.findAll({
    where: { postId: articleId, status: 'approved' },
    include: [{ model: User, attributes: ['id', 'username', 'avatar'] }],
    order: [['createdAt', 'ASC']]
  })
  
  // 2. 构建树形结构
  const commentMap = new Map()
  const rootComments = []
  
  // 创建映射
  allComments.forEach(comment => {
    comment.children = []
    commentMap.set(comment.id, comment)
  })
  
  // 构建父子关系
  allComments.forEach(comment => {
    if (comment.parentCommentId) {
      const parent = commentMap.get(comment.parentCommentId)
      if (parent) parent.children.push(comment)
    } else {
      rootComments.push(comment)
    }
  })
  
  return rootComments
}
```

```nginx
        try_files $uri /index.html;
    }
    
    # API反向代理
    location /api/ {
        proxy_pass http://backend:3000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

```bash
mkdir -p $BACKUP_DIR
```
