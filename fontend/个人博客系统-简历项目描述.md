# 全栈个人博客管理系统

## 项目概述
基于 Vue3 + Node.js + MySQL 开发的企业级博客内容管理系统，支持多用户角色权限管理、富文本编辑、文件上传、评论互动等完整功能。项目采用前后端分离架构，具备高度可扩展性和安全性。

## 技术栈
- **前端**: Vue 3.5 + Vite + TypeScript + Pinia + Vue Router + TailwindCSS
- **编辑器**: Vditor (支持 Markdown + 富文本编辑)
- **后端**: Node.js + Express + JWT 认证
- **数据库**: MySQL 8.0 + 多表关联设计
- **部署**: Docker Compose + Nginx 反向代理
- **开发工具**: ESLint + Prettier + Git 版本控制

## 核心功能亮点

### 🔐 用户权限管理系统
- **多角色架构**: 超级管理员、管理员、编辑、作者四级权限体系
- **JWT认证**: 基于Token的无状态认证，支持自动续期
- **多登录方式**: 支持用户名/邮箱/手机号三种登录方式
- **权限控制**: 前端路由守卫 + 后端接口权限双重校验

### ✍️ 智能编辑系统
- **富文本编辑器**: 集成 Vditor，支持 Markdown 实时预览
- **图片智能处理**: 
  - 拖拽/粘贴上传，自动SHA256去重
  - 图片压缩与尺寸控制
  - 本地blob预览避免401错误
  - 支持批量处理与智能删除
- **内容版本控制**: 自动保存文章修订历史，支持版本回滚
- **草稿自动保存**: 防止编辑内容意外丢失

### 📝 文章管理系统
- **状态管理**: 草稿、已发布、归档三种状态流转
- **SEO优化**: 自动生成友好URL、meta描述、关键词
- **分类标签**: 支持多级分类和多标签关联
- **批量操作**: 支持文章批量发布、归档、删除等操作

### 💬 评论互动系统
- **楼中楼回复**: 支持多级嵌套评论展示
- **内容审核**: 评论发布前审核，防止垃圾内容
- **状态管理**: 正常、屏蔽、删除三种状态控制

### 📊 后台管理系统
- **数据可视化**: 用户、文章、评论等关键指标统计
- **操作日志**: 完整记录所有管理操作，支持审计追溯
- **文件管理**: 统一的附件上传、预览、删除管理
- **系统设置**: 站点配置、邮件设置等系统参数管理

## 技术难点与解决方案

### 1. 图像处理优化
**挑战**: 大量图片上传导致存储压力和加载性能问题
**解决方案**: 
- 前端SHA256哈希去重，避免重复上传
- 图片自动压缩和尺寸适配
- 预览图blob URL本地化处理
- 智能清理未使用的临时文件

### 2. 富文本编辑器集成
**挑战**: 复杂的编辑器功能与Vue3组合式API的集成
**解决方案**:
- 自定义Vditor组件封装，支持v-model双向绑定
- 事件监听与生命周期管理优化
- 自定义插件扩展编辑器功能

### 3. 权限控制架构
**挑战**: 复杂的多角色权限管理和前后端一致性
**解决方案**:
- 基于RBAC模型的权限设计
- 前端路由守卫 + 后端中间件双重验证
- JWT Token自动刷新机制

### 4. 数据库设计优化
**挑战**: 复杂业务关系的数据建模和查询性能
**解决方案**:
- 规范化数据库设计，减少数据冗余
- 合理使用索引优化查询性能
- 软删除机制保护重要数据
