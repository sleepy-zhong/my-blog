# 文章管理功能说明

## 功能概述

文章管理模块提供了完整的文章CRUD操作，包括：
- 文章列表展示
- 新建文章
- 编辑文章
- 删除文章
- 文档导入
- 结构化内容编辑

## 主要功能

### 1. 文章列表
- 支持分页显示
- 支持按标题搜索
- 支持按状态筛选（草稿/已发布/已归档）
- 显示文章基本信息：标题、作者、状态、分类、标签、浏览量、创建时间

### 2. 新建文章
- 支持文档导入（docx、md、txt、rtf、pdf）
- 结构化内容编辑
- 实时预览
- 自动生成slug
- 支持设置文章状态

### 3. 编辑文章
- 复用新建文章的编辑组件
- 支持修改所有文章属性
- 保持原有的结构化内容

### 4. 删除文章
- 确认删除提示
- 支持批量删除（待实现）

## 技术实现

### 前端组件
- `ArticleManage.vue` - 文章管理主页面
- `StructuredContentEditor.vue` - 结构化内容编辑器
- `StructuredContent.vue` - 结构化内容渲染器
- `Pagination.vue` - 分页组件

### API接口
- `GET /api/articles` - 获取文章列表
- `GET /api/articles/{id}` - 获取文章详情
- `POST /api/articles` - 创建文章
- `PUT /api/articles/{id}` - 更新文章
- `DELETE /api/articles/{id}` - 删除文章
- `POST /api/articles/import` - 导入文档

## 使用说明

### 1. 访问文章管理
- 登录后访问 `/admin/articles`
- 需要管理员或编辑权限

### 2. 新建文章
1. 点击"新建文章"按钮
2. 可选择上传文档或手动编辑
3. 填写文章标题、摘要等信息
4. 使用结构化内容编辑器编辑内容
5. 设置文章状态
6. 点击"保存"完成创建

### 3. 编辑文章
1. 在文章列表中点击"编辑"按钮
2. 修改文章信息
3. 使用结构化内容编辑器修改内容
4. 点击"保存"完成更新

### 4. 删除文章
1. 在文章列表中点击"删除"按钮
2. 确认删除操作
3. 文章将被永久删除

### 5. 搜索和筛选
- 在搜索框中输入关键词搜索文章标题
- 使用状态筛选器筛选不同状态的文章
- 点击"刷新"按钮重新加载数据

## 注意事项

1. **权限控制**：只有管理员和编辑角色可以访问文章管理
2. **文件上传**：支持多种文档格式，自动解析为结构化内容
3. **内容编辑**：使用结构化内容编辑器，支持富文本编辑
4. **数据安全**：删除操作需要确认，防止误删
5. **性能优化**：支持分页加载，避免一次性加载过多数据
