# 项目目标

## 当前仓库目标

- 维护一个可部署的技术博客工作区：Vue 3 前端、Express + Sequelize 后端、MySQL / Redis / Nginx / Docker 配套。
- 保持公开站点、后台管理、附件链路、登录会话、文章评论和部署配置的一致性。
- 让任务在没有 Git 仓库上下文时，仍然能靠明确的文档装载顺序完成分析、执行、验证和复盘。

## 治理目标

- 让执行者在开始任务前知道该读哪些文档，不再依赖“猜目录”。
- 让高风险任务默认包含成功路径、至少一条失败路径、剩余风险和回滚/止损思路。
- 让经验先进入 `memory/`，避免把一次性结论直接写死成规则。
- 让现有专题文档继续保持权威地位，而不是被新的治理文件覆盖。

## 非目标

- 不重建一套脱离现有实现的“理想架构”。
- 不把 `fontend-minimal/` 当成主工程接管，除非后续任务明确启用它。
- 不把运行产物、上传文件、日志或第三方依赖目录纳入常规改动范围。
