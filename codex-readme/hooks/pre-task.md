# pre-task Hook

开始任何任务前，至少完成以下检查：

1. 明确任务类型：前端、后端、鉴权、公开态、附件、Redis、部署、SQL 或治理文档。
2. 读取根级 `AGENTS.md` 指定的最小文档集，并按 `project/task-router.md` 选择路径规则和场景规则。
3. 列出将要改动的真实路径，以及明确不应改动的产物目录。
4. 做一个最小计划：
   - 准备怎么改
   - 影响哪些契约
   - 准备怎么验证
5. 做风险识别：
   - 是否涉及登录 / 权限 / 文章公开态 / 评论审核 / 上传 / Redis / 部署
   - 至少一条失败路径是什么
   - 回滚或止损思路是什么

如果第 2 步无法确定该读哪些规则，先回到 `codex-readme/project/task-router.md`，不要直接开改。
